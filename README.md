# Лабораторная работа 2. Потоковый анализатор файлов

## Описание
Консольная программа для потокового анализа логфайлов форматов csv и jsonl. Программа построчно читает логи, подсчитывает статистику по уровням и источникам, сохраняет итоговый отчёт в json файл.

## Структура файлов
- `src/streamstats/__main__.py` — точка входа и парсинг аргументов
- `src/streamstats/constants.py` — константы
- `src/streamstats/models.py` — класс события и проверка полей
- `src/streamstats/parsers.py` — построчное чтение файлов
- `src/streamstats/analysis.py` — подсчет статистики
- `src/streamstats/report.py` — сохранение json-отчета
- `src/streamstats/errors.py` — классы ошибок
- `tests/` — тесты

## Обработка ошибок
По умолчанию при ошибке в строке программа останавливается и завершается. Если передан флаг `--skip-invalid`, неправильные строки игнорируются, в консоль выводится предупреждение, а программа продолжает работу.

## Примеры запуска

Анализ файла с сохранением отчёта:
```bash
python -m streamstats analyze log.csv --format csv --output report.json
```

Анализ файла с игнорированием неправильных строк:
```bash
python -m streamstats analyze log.jsonl --format jsonl --skip-invalid
```

## Тестирование

Запуск всех тестов:
```bash
python -m pytest
```

Проверка стиля кода:
```bash
ruff check .
```


## Дополнительные задания

- Отчёт csv без дублирования расчётов:
  Программа автоматически генерирует отчёт в формате CSV, если в `--output` передан файл с расширением `.csv`. Файл не читается заново, используется уже собранная статистика.

- Ленивые фильтры потока:
  События фильтруются с помощью генераторов без загрузки в память. Добавлены аргументы командной строки: `--filter-level` и `--filter-source`.

Пример использования дополнительных функций:
```bash
python -m streamstats analyze log.csv --format csv --filter-level ERROR --filter-source backend --output report.csv
